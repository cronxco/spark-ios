Apple rebuilt Siri on Foundation Models — what changed

The new Siri runs on-device first and escalates to Private Cloud Compute only when a request needs it.

App Intents now carry semantic indexing via IndexedEntity.
On-device models handle summarisation and short reasoning.
Third-party apps expose entities rather than raw intents.

The practical shift for developers is that Siri now reasons over indexed entities, so an app is only as discoverable as the entities it publishes.
